# Google Calendar для Luna

Luna читает и добавляет события через сервисный аккаунт Google. Вход с кодом на экране («устройства с ограниченным вводом») календарь не разрешает, а для обычного входа через Google у Luna нет публичного адреса. Поэтому владелец один раз создаёт сервисный аккаунт, а каждый человек открывает ему доступ к своему календарю.

## Владелец, один раз

1. Откройте [console.cloud.google.com](https://console.cloud.google.com) и создайте проект, например `luna-family`.
2. «APIs & Services» → «Library» → найдите **Google Calendar API** → «Enable».
3. «IAM & Admin» → «Service Accounts» → «Create service account». Имя, например, `luna-calendar`. Роли не нужны.
4. Откройте созданный аккаунт → «Keys» → «Add key» → «Create new key» → JSON. Файл скачается.
5. Положите файл на ПК с Luna и запишите его в `.env` одной строкой:

   ```bash
   python3 -c 'import json,sys; print("LUNA_GOOGLE_SERVICE_ACCOUNT=" + json.dumps(json.load(open(sys.argv[1]))))' ~/Downloads/luna-family-*.json >> .env
   docker compose up -d --no-deps luna-assistant
   ```

6. Удалите скачанный файл. Ключ хранится только в `.env`, его нельзя коммитить.

## Каждый член семьи

1. В Luna: «🔔 Напоминания» → «📅 Календарь». Luna покажет адрес сервисного аккаунта.
2. Откройте [calendar.google.com](https://calendar.google.com) в браузере. В приложении на телефоне такой настройки нет.
3. Настройки → свой календарь → «Открыть доступ отдельным пользователям» → «Добавить» → адрес из Luna → «Вносить изменения в мероприятия».
4. В Luna нажмите «🔗 Подключить» и пришлите адрес календаря (для основного календаря это ваш Gmail).

После этого события дня приходят в утренней сводке, Luna отвечает «что у меня в четверг?», а «добавь в календарь стоматолог в четверг в 15:00» добавляет событие после подтверждения.

Задания со сроком («📝 Задания» в Luna) появляются в календаре событием на весь день, например «📝 Математика: № 125». Задания, сохранённые до подключения, переносятся при подключении. Отметка «✅ сделано» в Luna удаляет такое событие. Расписание уроков в календарь не попадает, оно остаётся в Luna и утренней сводке.

Событие, добавленное Luna, создаёт сервисный аккаунт. Оно видно и редактируется как обычное, а напоминания берутся из настроек календаря по умолчанию.
