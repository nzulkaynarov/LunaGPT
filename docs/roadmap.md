# План работ

Обновлено 13 ноября 2026, после аудита продукта. Подробный отчёт хранится вне репозитория, потому что репозиторий публичный.

## Сделано 13 ноября

- **Страховка.**
  - Ночные копии всех баз с проверкой восстановления и копией на Pi.
  - Сверка семьи с Pi больше не удаляет людей.
  - Фоновые циклы Luna под надзором, на сбой Luna отвечает человеку.
  - Новые ключи Langfuse.
  - Open WebUI и Redis убраны.
  - Лимиты памяти контейнеров.
  - Тесты изолированы от боевых данных.
- **HomeSec.**
  - На Pi ставятся только коммиты с зелёными проверками, с откатом.
  - Родителям приходит тревога, если правила перестали применяться.
  - На Pi работают сетевой экран и вход по SSH только по ключу.
  - Пауза для любого ребёнка, его устройства или общего устройства на выбранное время.
  - Напоминания о запросах времени, недельная сводка.
- **Измерение.** Учёт использования Luna без текста и недельный отчёт хозяину.
- **Платформа.**
  - Удалены роутер, RAG, контур обратной связи, Open WebUI и Piper.
  - Код запекается в образ, миграции идут отдельным шагом, `scripts/deploy.sh` с откатом.
  - Образы закреплены, у шлюза один рабочий процесс.
